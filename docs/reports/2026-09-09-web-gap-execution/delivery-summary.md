## 重要边界

- 必检分母不因未发现、阻断或能力修订缩小；四种业务页面类型不增加第五类。
- 当前视口的局部原生结构负向，不等于产品或整站功能不存在；一般业务规则不得据此跳过。
- 新序列规则支持 `snapshot` / `llm`；多帧 `rule_engine` / `hybrid` 尚不支持且应显式拒绝，旧稳定规则不自动改变语义。
- 首批规则复用只针对显式允许的同一封存材料、完整上下文等价的重复消费；跨Capture/跨页面静态素材复用尚未启用，保留旧频率，不能将局部缓存优化称为全面规则频率策略完成。
- 已封存报告不按当前配置重写；正式正文需要在生成时保留解释，不能封存后临时拼接实时数据。
- 真实外站只在安全、合法、明确授权的范围执行；未成年人性内容、非自愿私密影像等风险分支不采集。无法安全覆盖时如实列未执行，不造“全量通过”。
