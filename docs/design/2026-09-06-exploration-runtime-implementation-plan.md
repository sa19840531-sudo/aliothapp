## 3. 核心边界

- 执行入口扩展现有 `CaptureCoordinator` 和动作账本；Agent 不能提供系统命令、脚本、设备连接地址或浏览器连接句柄。
- 安全策略来自平台任务与运行会话，不能仅相信 Agent 自报的低风险；观察、动作和目标参数逐项验证。
- CLI 观察和旧采集必须绑定同一个浏览器页面。另开一个页面的结果不能冒充当前页面的对比结果。
- CLI 只开放服务器列出的命令。官方工具支持脚本并不等于平台允许调用脚本。
- 命令已发送但结果不确定时，先观察并记为未知结果，不能通过更换执行器重复动作。
- 页面和状态记录基于本次运行已经提交的采集；局部 Tab、筛选、展开、排序通常保持页面身份；不同业务对象、页面职责和返回语义按证据区分。
- 启动弹窗底层未知时允许只有弹窗观察，不能虚构首页。外部落地、操作失败和未访问候选不增加业务覆盖。
- 任务结束后迟到数据不能改写已经封存的结果。路径查询不自动执行补采，也不宣称历史路线现在必然可用。

## 6. 页面图读接口与进度规则

- `GET /api/v1/workstation/tasks/{task_id}/page-graph`：沿用任务读取权限，按服务端选择的权威 Run 和当前 Epoch 查询。返回页面状态、真实转场及 `exploration_tree`，不接受客户端自行扩大租户或运行范围。
- `GET /api/v1/workstation/tasks/{task_id}/page-graph/recovery-route`：可按 `source_state_id`、`target_identity` 筛选，`limit` 限制在 1～100。返回 `routes`，每条路线有起点、终点和按顺序排列的 `steps`；不是把所有匹配跳转平铺为一条路线。
- 图与进度在同一只读、可重复读数据库事务内取得。页面图只投影既有记录，不改写 Coverage Snapshot、规则结果或报告。
- 同页同状态的多次采集归到同一状态版本；最新采集不能无条件继承旧采集的证据完成状态。
- 页面已访问、证据充分、质检完成、探索终结是不同事实。只有这些条件同时成立且没有待探索或阻断目标，才显示节点完成。质检规则发现业务问题，不等于页面证据缺失。
- 待访问入口属于 `targets`，不伪装成已到达业务页面。弹窗优先沿真实 Capture 父关系或转场关联底页，启动时底页未知则保留未挂接弹窗，不创建假首页。
- 历史恢复路线只使用同任务、Run、Epoch、会话内的可信低风险边，允许同业务状态的不同观察作为连续连接点。不同状态、不同会话、未知 Epoch、失败和外部页面不能被拼成恢复捷径。
- `legacy_unprojected` 表示仍有历史采集或动作未投影，不等于空图；此时可以诊断现有记录，但不返回已完成构建的恢复路线。

读侧验证记录：真实 PostgreSQL 5 项通过，覆盖进度、候选、连续恢复、未投影及权限/Run 选择；树与进度纯函数/用例 25 项通过。后续写侧变化需重跑，以上结果不代替真实设备和完整业务任务验证。

### 下一步必须统一的动作后证明

以下为待实施约束，不是已交付能力。统一执行已有命令结果继续保留，工作流生成的实际观察证明应同时供覆盖、候选访问和 Frontier 结算使用。

1. 分开记录执行成功、效果确认、业务页面到达和合法被动观察。校验实际前后 Capture、动作 ID、任务与会话绑定；旧轮证明和模型自报字段不得复用。
2. 无预期页型的普通点击仍允许自由发现：真实前后业务身份发生可验证变化时可以确认到达，不能一律要求预设页型。仅截图变化、同页型或命令成功都不充分；同页局部状态变化只证明该状态操作的效果。
3. 有明确目标时，同时核对实际页型与业务身份/对象；页型对齐结果不是动作证明。返回须验证目标应用和实际返回关系，仍在外部应用不得记 visited。
4. 滚动和观察不直接声明新页面到达。滚动依据当前可信偏移、可见范围或内容锚点确认效果；观察依据已验证 Capture 确认观察完成。保留合法等待、启动阶段计数与总体动作预算，不能因收紧到达条件而破坏有限探索的推进。
5. 弹窗身份变化但仍被新弹窗阻断时，记录替换或中间状态，不宣告全部关闭；真实关闭后独立检查底页。生命周期中间页可继续探索，但不能顶替原业务目标。
6. `app_exploration_turn._frontier_arrival_outcome` 消费工作流同一次动作的证明，不再以 expected 缺失或驱动 succeeded 另行判 visited；缺失或绑定不符时保持未证明。
7. 验收需同时覆盖无预设页型的真实新页、同页无效果、同类型不同业务对象、局部状态、外部返回失败、滚动、被动观察、弹窗替换及证明串轮。新断言不能只检查布尔值，还要核对候选、覆盖、Frontier 与终态结果一致。
