# H5 恢复绑定、自定义播放器与稳定后加载帧

日期：2026-10-16。需求分支 `h5-chain-reliability-and-entry-compatibility`，起点 HEAD `c9adb731ab1f5209b8ae1d43b8daed9443d71afd`。
本轮仍为未提交代码和隔离工程验证；没有原站任务重跑、服务重载、发布、业务库迁移或原表写回。

## 1. 确认的缺口

- 旧稳定帧主要看几何不变及 readyState，未证明确实呈现过当前资源的画面；同几何空壳、旧画面与内容变化都可能被误算稳定。
- 流程输入要求所有检查点同 Session；下一步规划也只读当前 Session 的尝试，恢复后会漏掉旧检查点，可能重复规划。旧数据库正例还把动作前旧来源交给依赖步骤，不能据其绿色结果证明来源连续性。
- 仅接受 fullscreen_tag=video 会拒绝自定义播放器包装；反过来仅靠容器进入全屏又会把小窗视频当视频全屏。两种情况须分别验证。
- 新观测字段追加在有界快照之后，必须继续遵守原512KiB上限，不能扩容或牺牲原证据来容纳字段。

## 2. 实施内容

### 稳定后加载帧

- 在隔离世界使用原生 `requestVideoFrameCallback` 记录实际呈现次数、媒体时间、解码尺寸和资源代次。只观察，不调用私有框架对象、播放/seek/网络接口或创建Canvas上下文。
- DOM元素替换有新实例；`emptied` 清空呈现记录并换代。资源身份留在隔离观察器内部，不额外持久化私有签名资源URL。旧资源帧、不同实例、错误尺寸、seeking、截断、遮挡和屏外样本不能通过。
- 采样保存实际PNG的视频视口区域摘要；精确读取器从已存PNG重新计算，拒绝自报摘要与图片不一致。两份样本仍要求两份实际制品引用及原帧来源bracket。
- 暂停：两次呈现事实须对应当前媒体时间，时间停止独立测量；稳定画面另须实际视频区域像素摘要一致，不能只看几何。
- 播放：实际呈现计数须前进；允许视频内容变化，不要求运动画面逐像素相同。暂停标记为false但呈现不前进保持未知，不据此证明加载后连续播放。
- `loaded_frame` 接入注册测量；观察仍是有界窗口，非全页原子截图或任意语义质量保证。实际合法纯黑影片不按单点颜色/像素数量误判空白。
- 新字段超出原快照大小上限时回退原快照，相关测量缺证；不提高快照、动作、模型或时间预算。没有前期呈现记录的已暂停播放器不自动播放来凑证明。

### 自定义播放器

- 覆盖显式 `aria-controls` 唯一指向真实原生video的控件包装。只读识别控件与媒体关系，动作仍经过原候选、风险裁决和Coordinator。
- 自定义全屏必须实际进入包含该唯一原生video的容器、控件归属一致、视频占视口至少一半；容器全屏但视频仍是小窗、控件指向其他媒体、图片全屏都不能补算。
- 不按CSS类名、按钮文案或私有状态对象猜播放器，不让纯Canvas播放器冒充原生video。

### 恢复后的精确绑定

- `next_checkpoint` 按同Run读取全部尝试，不只看新Session；多个旧尝试、reserved/gap或未满足依赖不靠新会话重放。准入在事务中按Plan/Checkpoint/Epoch串行核对逻辑检查点，不同物理Session也不能签发第二份动作许可。
- `checkpoint_recovery_binding` 有界追溯同Task/Run/Epoch的实际Capture父链及最新Manifest，校验Manifest载荷/hash/版本、真实附件闭包、物理角色和时间。
- 跨Session不能只凭父ID、同URL或equivalent标签通过：须实际 `qc_restoration_attempt`、原EvidenceRequest只读契约、有效等价评估/hash、业务不变量、正确来源等级、恢复动作账本和落点，以及原冻结deadline。
- 当前恢复策略必须允许新实例；无完整动作账本的新会话恢复、旧Epoch、晚到失败/待定Manifest、循环或不明父链继续不足。每个检查点自己的动作前后Capture仍要求同Session/文档/媒体实例，不把恢复放宽成跨实例动作拼接。
- 流程InputSet合同保存逐依赖恢复来源与Manifest引用；选择hash涵盖恢复链。通用Judge核对依赖实例变化，不接受无恢复证明的换文档/媒体。正式报告精确消费该恢复字段，晚到版本变化使旧合同不可再绑定新正式报告。
- 这只是既有权威恢复结果的证据消费，不创建恢复任务、绕过停止证明、解除隔离、覆盖旧尝试或自动重封存。

## 4. 剩余问题

- 仅旧Work的 `h5_browser_recovery` 等价标签、缺权威Restoration/动作链或停止证明的路径继续阻断；本轮没有为缺账本路径伪造证明或解封权限。
- 纯Canvas/WebGL、跨域iframe、Shadow DOM、私有播放器、缺显式控件归属、多原生播放器无法唯一选定的情况未补成自动通过；需要实际协议或对应案例。
- 有界父链超过上限、同检查点历史重复尝试或流程映射不清时保持缺口，不自动选一个旧pass或清理重复历史。
- 首次只见已暂停、没有呈现回调记录时不足。自定义控件动画/字幕可能改变暂停区域摘要，当前保持严格，不承诺所有包装都可裁决；帧回调接口不可用时也不猜加载完成。
- 连续观测义务已收紧，但未把所有普通视频页Publication合同改造成呈现帧必需合同；不能宣称原站加载态发布全部解决。
- 并发首次模型选择仍可能在逻辑检查点事务准入前发生；本轮保证后续实际动作唯一，未新增模型调用，不承诺重复选择窗口的费用已消除。
- 无只读契约的后台充值、缺原站私有高清映射继续阻断。原站支付/真实视频覆盖、复杂跨会话完整任务、长时间观察器容量及实际模型Token/CNY均未验证，不批准发布。
