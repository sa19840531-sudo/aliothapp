# 证据局部脱敏与业务复核契约

## 领域与接入

本能力用于 F10 的受控证据交付。来源为 `review.html` 的 F10，以及图2后续 B“目录和整组导出”（原图无可见行号）；原文和截图索引保留在 `.alioth/reports/2026-10-23-platform-evidence-reuse/`。局部脱敏是平台 Evidence 表示能力，当前工作台在既有任务详情的 H5 短流程材料面板接入，无新增菜单或路由；Web/App 及其他材料可直接复用通用接口，不据此宣告三端业务流程完成。

核心实体 `EvidenceRedactionPlan` 是不可变表示计划，与原 Artifact、Capture、Manifest、InputSet 分离。它冻结服务端核验的 Task、Run、Session、Capture、Manifest ID/version/hash、原件 ID/type/checksum/size/content type、规范化操作、策略版本、创建者、创建时间及派生 checksum/size/content type。`plan_hash` 绑定这些表示事实；`source_hash` 绑定可信来源。操作者租户与原件任务租户分别保留，跨租户管理员也必须通过当前对象范围校验。

计划保存在 `qc_evidence_redaction_plan`。不覆盖原件、不添加原 Capture 的附件、不改 Manifest、冻结输入、判定或 Gate。派生字节按不可变计划从原件重建，每次验证原件和派生摘要；策略未知、来源漂移或重建结果变化即拒绝。无 Capture 的历史原件可冻结 Artifact 来源，Manifest 字段明确为空，不伪造可信清单。

## 受控局部策略

策略版本为 `evidence-local-mask.v1`。`RedactionSpec` 禁止额外字段、混用方法、空局部选择与非整数坐标，最多128个选择器。

| 方法 | 参数与语义 | 保留与拒绝 |
| --- | --- | --- |
| `image_regions` | `image_width/image_height`，`regions[{x,y,width,height}]`；EXIF 转为正常显示方向后的原图整数像素，右/下边为开区间。 | PNG/JPEG/WebP 单帧源，最大4000万像素；在实际字节烧录不透明矩形，重新编码为无元数据 RGB PNG。范围外可见像素保留，透明隐藏像素移除。尺寸不符、越界、冲突或整幅覆盖拒绝。 |
| `text_ranges` | `ranges[{start,end}]`，UTF-8 解码后的 Unicode 代码点半开区间 `[start,end)`，与字节数、JS UTF-16 偏移分开。 | 只替换选中范围，保留其他业务上下文。整段覆盖、越界、重叠或重复拒绝；HTML 始终派生为 `text/plain`，不能执行。 |
| `json_pointers` | `pointers[]`，RFC6901 精确路径，选中值替换为 `[已脱敏]`。 | 保留未选业务字段及原数字字面量，金额和大整数不得浮点重编码。根、通配符、无效转义、不存在路径、重复/祖先冲突、重复键、NaN、层级或节点超限拒绝。 |
| `reviewed_unchanged` | 显式声明材料无需遮盖，不携带范围。 | 只能由有管理和原件授权者核对后冻结；图片仍重编码去元数据，HTML 仍为纯文本。不是空策略直通接口。 |

单份受控接口原件和派生件限制16 MiB，整组沿用64 MiB/1000成员上限。未知格式拒绝，不回退为原件，也不静默换成全幅遮盖。

`business_reviewable=true` 表示该版本保留了未遮盖的业务上下文，并有授权人员确认；它不代表自动识别所有个人信息、不代表隐私审查或业务规则通过。操作者须检查服务端生成的派生内容，确认遮盖范围及复核所需内容。修改范围后旧预览失效；无需遮盖的材料在界面中额外确认。局部材料仅用于复核交付，不自动替换 Judge 当前冻结输入。

## 接口与权限

通用接口均在 `/api/v2` 下，使用现有登录与对象权限。

| 接口 | 合同 |
| --- | --- |
| `POST /evidence/{artifact_id}/redactions/preview` | `{source_checksum,manifest_id?,manifest_version?,spec,review_confirmed}`；两个 Manifest 字段须同时提供。返回来源白名单、计划摘要、派生类型/大小/摘要及 `content_base64`。仅预览，不保存计划。 |
| `POST /evidence/{artifact_id}/redactions` | 同上，必须 `review_confirmed=true`；生成不可变版本。成功计划和创建审计在同一 PG 事务落库。返回公开版本摘要，不返回指令原文。 |
| `GET /evidence/{artifact_id}/redactions` | 返回 `{items,can_manage}`，各项为不可变版本的公开摘要。工作台按原件与精确 Manifest 身份筛选，历史版本不得混入当前导出。 |
| `GET /evidence-redactions/{redaction_id}/file` | 登录态读取服务端派生字节；前端验证派生摘要和大小，再展示或选入包。不申请原件票据，不以 CSS 遮罩代替派生材料。 |
| `POST /tasks/{task_id}/h5-shortflows/{execution_plan_id}/archive` | `{snapshot_hash,redaction_ids:{artifact_id:redaction_id}}`；固定 `mode=redacted`，每份当前绑定材料必须明确选择同源版本，禁止临时指令或额外/缺失成员。生成 `evidence-group-export.v3` 回执。 |

编辑、预览和创建需要 `evidenceRedactions:manage`、`evidenceExports:original`、`evidenceExports:redacted` 及原件的当前对象读取范围。沿现有静态角色权限，平台/体验中心管理员、公司管理员拥有管理权限；审计员和其他账号默认不获得新管理权限。权限字符串与对象数据范围分开，后续可接权限模型扩展。

读取版本、读取派生件及局部整组导出只要求 `evidenceExports:redacted`，叠加当前 Task/Artifact 对象范围和原件生命周期。只有脱敏复核权限的组件路径不加载原图。此处没有改变既有原件票据接口的授权合同，也没有把模式权限当对象权限的替代。

请求开始与交付前都检查权限。准备后重载当前账号、租户启用状态、权限和对象范围，复验来源；整组另外复验完整读快照。原件被待删/删除、来源改变、主体停用、换租户、撤权或快照变化均阻断。响应使用 `no-store`，HTML 不以活动类型交付。

## 审计和失败语义

迁移 `20261023_0146` 扩展既有 `qc_evidence_download_audit`，使用 `operation` 区分预览、创建、列表、派生读取和整组导出，关联请求 ID、原件摘要、派生摘要、`redaction_id/plan_hash/source_hash` 及操作者。成功、权限拒绝、来源损坏与处理失败都沿同一不可变链记录固定原因码，不保存存储路径或异常原文。创建成功的计划和审计原子写入；审计失败不留下成功版本。

任何字节或 ZIP 交付都必须在审计提交成功后发生；整组准备失败不能返回部分包。回执保留 Task/Run/Session/Capture/Manifest、角色/尝试、原件与派生摘要和策略/计划身份，只投影允许的结构字段；规则理由、原站标题、存储路径和局部指令不经回执绕过遮盖。

旧 GET 原件及 `evidence-conservative-mask.v1` 全幅/全文遮盖保持兼容，后者仍明确不可用于业务判读。局部脱敏使用独立策略版本和明确计划，不能把历史保守副本改标为可复核。有计划或扩展审计记录时0146禁止回滚，避免丢失表示及审计语义。

## 可复用验收

- 使用真实图片和文本/JSON，证明选中敏感内容消失、未选业务状态/价格/进度仍可读取，原件字节与数据库行不变；验证 EXIF、透明像素、动画、精确数字及 Unicode 范围。
- 公开接口覆盖只读脱敏主体零原件请求、管理权限缺失、不同对象/租户、创建确认、版本/摘要篡改、缺件、撤权、账号停用、审计失败；损坏计划在读原件前拒绝。
- 真 PG 验证原子创建、不可变计划与审计、精确历史 Manifest、来源串属、空库迁移往返及有数据拒绝回滚；以 Local/MinIO 原件服务读取，不用 mock 数字冒充真实字节。
- 整组覆盖全部成员及重复角色，拒绝遗漏、外来、错 Manifest/Run/大小、未知或损坏版本；交付前来源、对象、主体与读快照复验。
- 工作台覆盖桌面/窄屏、键盘坐标与拖拽缩放、服务端预览后确认、切材料/关闭/卸载的迟到响应、预览失败不能导出；只读复核器只加载实际派生字节。
