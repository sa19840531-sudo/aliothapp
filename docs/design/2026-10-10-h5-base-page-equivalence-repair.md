# H5 基础页补证层级误拒绝修复

## 范围与约束

只修 H5 通用恢复适配与确定性 Judge 的 H5 异常上下文，不改 App/Web 行为、探索排序、页型识别、关闭策略、动作或模型预算、冻结截止、Completion Gate。保护原未提交修改。当前批次 `20261010-104542` 不重启、不取消、不重跑，不回写历史记录。

## 真实案例

- Task：`25b95486-573d-4636-8e61-10d2ee36a352`；Run：`f9599592-6cf7-4c0c-a670-8db040dc40cc`。
- 请求：`evidence-request:c6488beeccd26d7a75620771e6174e3c4476232a943f49553ff126217f70af5e`。目标原 Capture：`2d6c1d0c-d70c-4220-a671-8604e7db7185`。
- 确定性判定因 `visible_text` 为空返回证据不足，但原异常出口传入 `packet=None`，导致请求的环境和业务维度为空、语义维度只有区域，结构目标为 `base_page`。
- 三次恢复帧依次为 `72295d83-a7cb-4c40-a1ea-fecaf2dd4dfd`、`54d97b7b-70aa-4e27-bdcc-c86628c93f2e`、`fd9a39e6-7d12-4e9e-a1c0-a43491d3c9b5`。两侧持久化页面图身份均 confirmed，同业务逻辑键、URL、video_list 页型，非外跳；原帧 popup/overlay，恢复帧 stable/base_page。
- 旧 H5 适配要求请求语义必须带标量 `page_state=popup`，缺失时不适配原层；公共三方比较因此拒绝旧 overlay 与目标 base_page。三次失败不证明网页发生业务变化。

## 最小修复

1. 两个确定性 Judge 证据不足异常出口传递已有观察包。仅在 H5 Web 且 Task、规则、原工作 Capture、实际目标来源 Capture 和 Manifest 绑定成立时，保留页面上下文和已有观察包 ID；结果仍为证据不足、置信度为零。
2. H5 基础页清障等价适配允许请求未带观察态；仍独立核实两侧持久化快照的身份、页型、地址、实际层级和状态。若请求带原观察态 popup，只在比较副本中适配；缺状态时不伪造状态。
3. 显式状态集合不适配，关闭前 `before` 角色不适配。剩余层、锁定状态、身份不明、页型或 URL 变化、Web 会话不适配。未改公共状态等价门禁。
4. 保留后续 Probe、制品/展示/时序要求和 Judge；不把“可开始补采”当作“已取得足够证据”。不增加跨 Capture 缓存或新调度策略。合法恢复的原有有界重试保持不变。
