# 规则证据选择与审阅导出契约

## 领域与接入边界

平台以 Task、Run、Session、Epoch、Journey Plan、Checkpoint Attempt、真实 Action、Capture、Manifest、InputSet 和原件建立可核对的证据链。规则选择、实际执行、质量门禁、只读审阅、对外交付分别负责自己的合同，不能互相替代。

选择内核位于 `domain/journey/rule_selection.py`，材料打包与错误归一位于 `application/evidence_archive.py`，历史和时间线投影位于 `application/evidence_review_projection.py`。这些模块不访问设备、浏览器或模型，也不包含产品点位、包名与页面文本特例。当前生产适配入口仍为既有 H5 短流程接口；共享模块可复用不等于 Web/App 已具备完整业务短流程。

继续使用既有工作台任务详情、规则编辑抽屉、截图查看器和原件票据下载，不增加菜单或路由。规则编辑沿原写权限，所有读与导出叠加原 Task 对象范围；复核权限不能替代任务读取权限。

## 按规则冻结输入

- `journey_rule_contract.evidence_conditions` 至少选择一个发布检查点，每项至少一份受支持证据义务。服务端按冻结执行计划计算传递依赖，按原计划顺序生成闭包；依赖的完整义务不能通过材料勾选削弱。
- 输入选择不修改完整执行计划、动作策略、恢复要求、截止或预算。非相关检查点缺口不应阻止已有充分证据的局部规则产出结论；完整流程的执行与证据义务仍独立约束 Gate 和正式报告。
- 新输入合同保存规则选择、原计划、真实 Attempt、Capture、Manifest 版本与摘要，和规则合同哈希共同冻结。不用当前页面、另一规则或最新成功材料拼接旧输入。
- 历史 `journey-input-contract.v1` 继续按原整流程语义读取，不用新选择重算旧摘要。新选择使用 v2，消费时从冻结规则重建闭包并核对。
- 旧 Page/Web 序列合同保持原语义；候选、页面类型、按钮存在和探索课纲进度不能制造真实 Journey 完成事实。Manifest 齐全性沿写入裁决，Gate 不自行重算或修订。

## 版本与时序审阅

- 检查点按计划顺序排列；实际 Action/Capture 时间线另行展示。真实时刻缺失须标为未知，不用 Attempt 创建时间、上传时间或 UUID 冒充实际发生时刻；同一时刻的稳定排序只为可重复展示。
- 连续采样读取精确 `checkpoint-observation.v1` 原件，显示样本顺序、单调采样时刻和间隔。单调时钟不能换算成墙钟时刻；截图引用只来自所选版本的真实成员和摘要匹配。
- Manifest 历史只展示同 Capture、同角色且身份核验通过的材料。明确原绑定、最新质量和历史只读状态；历史成员不回填当前绑定、规则输入或整组原件导出。
- 非截图材料通过原件票据鉴权后读取，核对字节数及 SHA-256。文本阅读有流式大小上限；HTML、DOM、XML 只作文本展示，不执行脚本或嵌入远端内容。超限材料保留原件下载入口。
- 关闭、切任务、切版本或卸载时清理进行中的读取；迟到响应不能恢复旧材料。历史质量不能被当前最新质量覆盖，历史可读也不代表仍可用于当前判定。

## 完整导出与不可变审计

- 复用原件读服务验证完整成员闭集，保留相同字节但不同角色、样本或尝试的材料。目录使用平台生成的稳定编号，不能使用原站标题或存储路径。
- 导出使用 `mode=original|redacted`，默认 original 兼容原入口。模式权限为 `evidenceExports:original`、`evidenceExports:redacted`，且始终叠加当前 Task 的对象读取范围。
- 每次整组请求产生唯一请求 ID，贯穿响应、回执和全部成员审计。成功、拒绝、缺件、摘要不符、存储错误、超时及快照漂移须使用固定原因码，不泄露存储路径或内部异常。
- 内容全部准备成功后，再次加载当前主体、权限、对象范围与读快照；审计整组事务提交成功后才能交付 ZIP。任何失败都不能返回部分材料包。空组、初始拒绝等没有可公开成员时保留请求级审计标记。
- 迁移 `20261023_0145` 扩展既有不可变下载审计，不新增平行审计表。旧票据记录接口保持兼容；有新导出记录时禁止回滚丢失审计语义。各条迁移 SQL 独立执行，兼容 asyncpg。
- 派生件保持原件不变，回执记录原件摘要、派生摘要、模式、策略版本和关联身份。当前保守遮盖策略用于来源与结构追溯，整图或原文移除的副本不可用于业务判读；未知格式拒绝整组，不标记为已脱敏。
- `evidence-local-mask.v1` 使用独立不可变计划，提供图像局部烧录、代码点文本范围、JSON精确字段及显式核验无需遮盖。通用接口、管理/复核权限、实际派生预览与明确版本整组交付见[证据局部脱敏与业务复核契约](证据局部脱敏与业务复核契约.md)。该策略不声称自动 OCR/个人信息识别，不能用全幅遮盖副本替代业务复核。

## 共享语义判定口径

正式与人工证据测试、单条与批量判定使用同一规则能力边界。Observation Packet 明确投影冻结 `input_contract`，页面文本和候选输入不能覆盖它。

人工材料组装的便利检查不能删除模型可见的原始义务；原合同在模型缓存键生成前恢复。沙箱无法提供的真实网络、动作、时序或媒体事实直接保留不足，多张人工截图不能替代。规则合同的安全投影若发生截断、字段移除或脱敏，模型请求前转配置复核，不生成现场补采请求，也不按删减后的合同判通过。

纯视觉规则可在实际截图充分时判读，不因无关结构缺失一律阻断。精确数值、阈值、网络、时序和动作因果规则需要相应实测材料；缺项保持 `evidence_insufficient`。事实已充分但有冲突或处于测量精度边界时再按合同转复核。系统提示词不再全局允许目测补齐，也不全局忽略确定性工具的不足。

提示词约束与受控传输测试不等于真实模型质量保证；真实模型对照、三端原站与真机验收分别留证。
