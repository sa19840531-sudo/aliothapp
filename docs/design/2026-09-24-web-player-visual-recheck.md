# Web 播放器视觉补判

Web 探索在 `content_detail` 或 `video_detail` 的 ready Capture 上，只有可信 UI 快照中出现唯一、非广告、非推荐区域的原生视频候选时尝试补判。候选必须与同一 Capture 的 DOM 派生元素及可用的 `media_state` 一致。不能唯一定位、页面身份变化、媒体仍在加载或补图不可信时记录 `uncertain`，不修改正式页型。

目标已处于视口时使用当前 Capture；否则复用现有受控主体滚动，把视频元素滚到视口中央，再读取动作后的 ready Capture、当前视口截图、DOM、UI 快照和 `media_state`。补判保留 ready 首屏页型证据；滚动截图只作为独立播放器观察证据。

模型只返回播放器可见性、播放或暂停控件的归一化截图坐标框、置信度和理由。坐标必须处于当前截图和目标矩形内才保存；它不授予点击权限，不覆盖正式页型，也不把正文内嵌视频升级为 `video_detail`。结果与源及补采 Capture ID、页面逻辑身份、截图尺寸、目标指纹和证据 ID 一起留在 Capture 元数据中，供后续质检读取。补判失败是可选证据缺口，不能使已经成功的页面探索失败。

本阶段只实现静态视觉补判，不启动播放或录屏，不改 App/H5 代码。
