# 文档索引

本目录保留现行规范、设计契约、部署说明及仍有用途的验收材料。已完成的一次性计划、旧批次输入和重复报告通过 Git 历史追溯。

## 日常入口

- [专项能力与高频回归规则](专项能力与高频回归规则.md)：各模块已确认的约束和高频回归边界。
- [绿色规则三端实施规范](绿色规则三端实施规范.md)：绿色八条规则的现行定义、证据合同与三端职责。
- [绿色规则共享判定与外部依赖](reports/2026-10-21-绿色规则共享判定与外部依赖.md)：当前实现范围、验证结果和待其他端或产品提供的材料。
- [Web白名单直登配置](Web白名单直登配置.md)：Web登录配置和会话边界。
- [设计索引](design/README.md)：领域架构、接口、执行流程和专项设计。
- [单机部署与回滚](deployment/2026-07-17-alioth-single-host-deployment-guide.md)：生产Docker Compose、CI/CD及发布操作。
- [H5验证资料索引](validation/README.md)：当前受控验证结论、已知失败和原始记录。

## 目录用途

| 目录 | 保留内容 |
| --- | --- |
| `design/` | 架构、领域、接口与执行契约 |
| `deployment/` | 部署、验收、发布与回滚操作 |
| `data/` | 生产或初始化读取的数据、规则及Journey输入；清理须先核对调用方 |
| `validation/` | 可复用验证说明、当前失败夹具及必要原始记录 |
| `reports/` | 仍被现行规则、代码或验收引用的报告和配套证据 |
| `outputs/` | 外部问题原表、截图链接及归属核对材料 |
| `ui/` | 产品界面参考 |

## 运行产物

本地测试报告、截图、日志和核验输出放在仓库根目录的`.alioth/reports/`，不作为日常文档入库。七站2026-10-21测试及复跑资料已整理到该目录，任务原件继续保留在`.alioth/evidence/`。

清理不得切断Task、Run、Session、Manifest与原件的关联。需要长期入库的验收材料只保留有明确用途和索引的内容；更新已有规范和索引，避免为每轮操作新增一份说明文档。
