# H5 截止后的终态结算审查

日期：2026-09-07。基线：`6c4129b5`。范围：观星第 5 项“有界自由探索”的 H5 截止收尾；不扩展补采、CLI 权限或页面图功能。

## 问题与处理

动作或失败重观察完成后，共享 deadline 可能已经到达。原 Runner 仍发布后继，仓储拒绝后把本轮归类为基础设施失败，丢失返回值中的结果引用；此前仅修复结算函数并不能解决这一层。

- 截止前仍正常原子提交后继；截止时及之后，形成当前父 Work 的 `budget_exhausted` 终态，不发布可领取的新 Work。
- 保留同一轮的协调结果与 Capture 引用；失败重观察保留已有 Capture 和错误信息，不虚构成功动作或 After。
- 同 Session 的动作/重观察结算：预算、累计动作数和已有调度摘要进入现有 terminal payload；父 Work 的身份、原始载荷、来源 Capture 和 deadline 不变。H5 覆盖仍使用既有 Coverage Snapshot，在同一事务保存。
- 仅明确的截止拒绝能进入这一分支。任务阶段、租约、版本、归属失败继续拒绝；取消和租约丢失不能被伪装成预算耗尽。
- 终态结算与任务封存使用同一锁边界，并校验结果 Capture 的实际 Run、Session 和固定 Epoch。没有延长截止时间或打开新派发入口。
- 已有浏览器恢复的三个后继提交入口同样检查截止。跨 Session 的恢复仅在原父 Work 保存终态和恢复结果引用，不走同 Session 的覆盖结算，不把恢复截图自动计为业务覆盖；没有放宽数据库的 Session 校验，也没有新增跨会话回放。
- 直接返回终态的动作轮保留实际动作和 After 引用；纯终态确认不虚增动作。已有阻断/证据不足原因不能因为补计数而丢失。
