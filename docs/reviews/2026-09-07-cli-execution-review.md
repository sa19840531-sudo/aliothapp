# CLI 观察与普通操作交付审查

日期：2026-09-07。对应观星的统一执行、受限命令、CLI 只读观察和 CLI 普通操作四项任务中的 Web/H5 部分。

## 交付内容

- CLI 固定 0.1.19，依赖使用锁文件；安装及连接时验证完整补丁摘要。观察和动作使用任务独占的浏览器及 CLI 目录，不读取用户全局配置或继承业务秘密环境变量。
- `off / observe / actions` 分阶段启用，默认 `off`。观察模式读取同一实际页面的结构、截图、请求、标签和地址，并独立保存对比记录；不把对比帧替换成正式 Capture。
- CLI 仅开放服务器允许的命令及参数。普通点击绑定平台预检的节点 ID 和语义摘要；节点被替换或变成付款/外链目标时拒绝。滚动、返回和导航同样经过范围校验，不能输入任意脚本或命令。
- BrowserCaptureRuntime 中的 H5/Web V2 以及旧页面采集入口继续走共享 Coordinator、服务端范围读取、租约和动作账本。Web V2 原有控制面不另起一套实现。
- 一次动作在发送前选择 CLI 或现有专用执行器；发送后超时、取消或结果未知时，保存未知回执并仅重新观察，不切换执行器重放。
- 密码登录仍走专用秘密输入窗口，同时接入公共动作账本。公共合同只保存安全意图；字段清空前不保存含密码的后态，登录是否成功由实际认证观察确认。
- 两份 API Dockerfile 安装锁定 CLI；API/Worker 的 Compose 配置加入 init 回收子进程，避免 daemon 关闭后留成僵尸进程。

## 已有真实浏览器证据

合并后的当前源码只读挂载到独立 Linux/ARM64 容器，非 root、只读根目录、无外网，以 localhost 测试站点运行 CLI 与 Runtime Holder：**60 passed，73.94 秒，退出码 0**。补丁检查通过，Node 补丁测试 **3 passed**。

覆盖手机 DPR=2/3、桌面 DPR=1、同页截图逐像素比较、普通操作、风险目标、节点替换、未知动作、环境漂移、输出超限和进程清理。首次未加 init 时的 5 个关闭清理失败没有忽略；正式 Compose 已加入 `init: true`，直接运行容器必须使用 `--init`。完整环境、镜像摘要和命令见 [CLI 运行说明](../design/2026-09-06-playwright-cli-runtime.md)。
