# H5 五站补充导航修复实施计划

> 状态：用户已确认实施；`ranking` 不纳入当前页面类型，帖子详情统一归 `content_detail`。

## 目标

在不恢复 `ranking`、不扩大高风险点击范围的前提下，补齐五站真实列表标题、折叠区视频、个人中心入口、六栏导航与无关闭按钮默认页弹窗的确定性探索能力，并修正候选失败后过早终止 sibling 探索的问题。

## 实施步骤

1. 先增加失败回归：真实内容/帖子标题结构、站点 3 第二屏视频和帖子详情路由、站点 5 签到/会员/设置结构、站点 4 六栏导航、默认页蒙版，以及 `ranking` 不进入 Catalog/候选/报告口径。
2. 扩展列表详情能力合同与 Snapshot 复核，所有帖子详情仍输出 `content_detail`。
3. 增加一次性视口滚动候选；滚动后必须重新 Capture，禁止复用滚动前标题坐标。
4. 扩展 profile 的 activity/payment/settings 受信结构，支付能力只允许进入会员页，不允许提交交易。
5. 修正底栏结构映射、动作到达证明和候选级恢复，使 URL 或选中态真实变化后继续同源 sibling 探索。
6. 增加“设置默认页面”无关闭按钮的精确蒙版能力，点击后重新取证并验证弹窗消失。
7. 清理现行代码、测试、技能和报告中将 `ranking` 当作可覆盖页型或可探索目标的遗留；历史沿革仅保留明确的“已移除”说明。
8. 更新 `docs/专项能力与高频回归规则.md`，运行定向测试、扩展 H5 回归、Ruff 与 `git diff --check`。

## 边界

- 不新增数据库迁移。
- 不新增 `post_detail` 页型。
- 不输入搜索词、不恢复 `ranking`、不点击支付/开通后的确认按钮。
- 滚动、点击和蒙版关闭均使用当前 Capture 绑定的受信结构，并采用有界次数。
