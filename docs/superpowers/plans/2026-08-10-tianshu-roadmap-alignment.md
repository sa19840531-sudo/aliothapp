## W17-W20 实现边界

W17-W20 在接入 Worker/Interaction Runtime 前，只实现可复用的领域判定与阶段推进逻辑：

- 输入：当前页面类型、页面状态、倒计时/弹窗观测、候选关闭动作、采集引用、已执行阶段步骤。
- 输出：下一步阶段动作、是否需要重新采集、是否完成、是否阻塞、阻塞原因。
- 不直接写规则结果。
- 不直接调用浏览器或 App Driver。
- 不直接封存任务。
- 后续由 Interaction Runtime 执行动作，由 Capture 产生证据，由 Completion Gate 做最终收口。

## 成功标准

- 后续分支命名和提交说明不再把 W17 用作 `PageTypeAssessment` 运行时接入。
- W17/W18 代码可以在没有数据库迁移的情况下通过领域单元测试。
- 等 W15/W16 完成后，只需要增加 Repository 接线，不重写阶段判定逻辑。
- 旧历史分支不会被误合并导致 `PageTypeAssessment` 回退。
