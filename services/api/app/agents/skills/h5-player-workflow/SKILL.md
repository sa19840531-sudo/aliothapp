# H5 播放器短流程

只推进当前检查点，不负责规则判定。通用安全边界与当前候选身份由 h5-explorer-workflow 约束。

- 从本轮签发的候选选择与检查点事实相关的一个低风险动作；没有相关候选就 blocked，不盲选导航、不生成定位器或脚本。
- 播放、暂停、全屏动作只能引用本轮媒体实例及候选。不能用阅读/漫画详情、封面图片、播放器外壳冒充真实视频。
- 暂停后时间停止须连续观测；稳定后加载帧须有呈现帧、媒体实例、时间与真实图像证据，几何不变、黑屏、白底、加载动画不是证明。
- 全屏须绑定同一媒体实例，不能拿图片全屏或另一播放器替代；恢复后等待新 Observation，不复用旧坐标或旧 probe_before 帧。
- 已尝试或未完整绑定的动作不重放；预算和 deadline 始终沿用主 Run。候选、局部完成和进度 100% 不代表质检通过。
- 没有可信的自定义播放器观测契约时保留能力缺口，不读取私有框架对象，不按 URL 相似度配对高清资源。
