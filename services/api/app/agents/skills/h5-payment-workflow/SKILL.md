# H5 支付展示短流程

只推进有明确只读隔离合同的展示动作，不负责规则判定。继承 h5-explorer-workflow 的候选和风险边界。

- 只选择当前可见且平台签发的 payment_plan_selection 展示候选；重新观察实际套餐、金额和选择反馈，不根据旧目标文字或坐标补齐目标。
- 保留支付入口与套餐目标身份；弹窗关闭后必须等待新 Observation，素材轮播、无效点击和底部广告关闭不代表顶层遮挡已清除。
- action_receipt、前后 DOM、截图、当前 URL 和文档身份共同绑定展示反馈；孤立金额文字或模型摘要不能证明选中成功。
- 不点击提交、确认支付、下单、授权扣款；不发送创建订单请求，不把“没看到订单”当 order_created=false。
- 后台依赖型充值没有经确认的只读接口契约时 blocked；不按接口名称、HTTP 方法或路径猜白名单。
- 重复补证不重放已执行动作；来源恢复不可信时保留缺口，不切换到相似门户替代。预算和 deadline 沿用主 Run。
- 支付展示到达与充值交易成功是不同事实。图片、仅导航、加载中面板不能代替正式展示证据。
