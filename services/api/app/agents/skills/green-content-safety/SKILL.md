# 内容安全与实际覆盖判读

仅在冻结规则显式声明本程序时读取，具体规则正文、适用范围、受控政策版本和人工复核策略均以该Task保存的规则合同为准，不从当前磁盘替换历史正文。

1. 只读取正式Task、Run、Session、Epoch及同一业务内容范围内已有的截图、可识别文字、Manifest和原件身份。核对实际覆盖与完整性；未采到不等于内容安全。
2. 按冻结合同检查首页、一级目录中的等价首页、首页内容列表及其他内容列表的前两屏范围；按原文19:9范围扣除固定功能与导航。不得用缩略图、自报摘要或局部样本冒充完整覆盖。
3. 排除广告须有可追溯来源，不能由模型见到广告样式就任意剔除。范围或排除依据缺失时明确记录证据缺口。
4. 图文联合判读；涉未、涉政、涉恐分别输出状态、置信度、实际触发证据和复核建议，不以一项通过抵销其他风险或缺证。
5. 不猜测精确年龄。年龄、类别或政策含义不确定时保留manual_review，并交给原复核事务。普通战争、枪械等元素不能单独证明涉恐。
6. 具体红线必须引用规则中冻结的受控政策版本。没有政策依据不得由模型发明红线或自定通过阈值；已有明确反例与尚缺材料分别保留。
7. 只复用现有截图、文字和语义Gateway；实际模型调用绑定正式消费者Task与Run及用量审计。结论交由既有结果Writer、复核、报告和完成事务，不另建结果表。
8. 本Skill不扩大UGC输入风险规程，不授权采集、点击、登录、弱网、支付或联系客户。公开结果按字段白名单脱敏，保留原件回溯但不暴露存储路径、敏感响应或凭据。
