# app/shared 前端共享包

供 `admin` 与 `workstation` 两个前端项目共用的代码包，避免重复实现。

## 计划内容

- **通用 UI 组件**：与业务无关的基础组件（表格、表单、上传、截图预览等）。
- **API client**：统一封装后端 `services/api` 的请求客户端（鉴权头、错误处理、重试策略）。
- **TypeScript 类型定义**：与后端接口契约对应的请求/响应类型，建议与后端 OpenAPI schema 保持同步（后续可考虑从 OpenAPI 自动生成，减少手写类型漂移）。
- **通用工具函数**：日期格式化、权限判断、枚举映射（如 `qc_rule.category`、`execution_status` 等后端枚举的前端展示映射）等。

## 约定

- 仅沉淀两个及以上前端项目共用的能力，业务特有逻辑保留在各自项目内。
- 变更需兼顾 `admin` 与 `workstation` 两侧的兼容性，避免破坏性改动未同步升级。
